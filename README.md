# Weekly Sales Summary

A Jupyter Notebook that summarizes fictional weekly sales data using various Python functions.
Built as part of Lesson 0.4 of Coding Temple's AI Data Analytics Foundations course.

## What it does

The Jupyter Notebook lists a dictionary of fictional sales values for each week up until the sixth week.
Then various Python functions were used in displaying the data after being manipulated by built-in arithmetic functions
in Python.

## How to run

You need to make sure that you have the Jupyter Notebook extension installed in VS Code.
After confirming that, all you have to do is click the run button above any functions that are in the notebook
to see data results.
